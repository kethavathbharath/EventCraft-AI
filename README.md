# EventCraft AI: Celebration & Event Planner

A GenAI-powered planning assistant for **weddings, birthdays and community events**. It produces personalized ideas, an editable budget, a countdown timeline and a vendor checklist, and it lets you refine the plan by chatting. Demo project for PromptWars Virtual.

**Live demo:** https://claude.ai/artifact/Vfk6KVTcBDKNzw1nvusbhy

## How it meets the brief
| Requirement | Where it lives |
|---|---|
| Weddings, birthdays, community events | Ten event types (shaadi, sagai, mehendi & sangeet, griha pravesh, godh bharai, namkaran, anniversary, festivals and more) plus three one-click samples |
| Personalized ideas (GenAI) | "Personalized ideas" section, generated by Claude from your theme, city, budget and guests |
| Budgets | Editable category split, live total, over-budget warning, share bars |
| Timelines | 9-step countdown with dates, checkboxes and a progress bar |
| Vendor checklists | Per-category status (To contact / Contacted / Booked), quote and notes |
| Refinement | Chat: "make it cheaper", "add a vegan menu", "make it outdoor" |
| Saved plans | "My saved plans" section: save under a name, reopen, delete; persists in the browser (up to 30 plans) |
| Export | Download as .txt or print |

## Architecture
Single self-contained `index.html` (vanilla JS, no dependencies, no build step).
- **State:** one `plan` object, saved to `localStorage`.
- **AI layer:** `aiPlan()` and `aiRefine()` call the host's `sample` capability. If AI is unavailable, built-in rule-based logic takes over (demo mode, no API key needed).
- **Rendering:** a safe `h()` DOM builder that writes text nodes only.

## Run
```bash
npm install
npm test          # 57 tests (Vitest + jsdom + axe-core)
npm start         # serves index.html locally (AI falls back to demo mode outside claude.ai)
```

## Quality, security, accessibility
See [SECURITY.md](SECURITY.md). Accessibility: WCAG 2.1 AA targets: labelled inputs, ARIA live regions, keyboard support, skip link, 44px targets, light/dark themes, reduced-motion support, responsive from 320px.

## Known limitations
No server component; AI output is validated and clamped client-side. Currency is formatted as INR.
